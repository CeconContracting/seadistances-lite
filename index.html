Settings

Only the Vessel Tracker needs a key - everything else works without one. To get a free key:
1. Go to aisstream.io and sign in (it uses a GitHub account - create one free at github.com if needed).
2. Open API Keys and click Create API key.
3. Paste the key above and Save. It is shared with the team through the app folder.

Vessel Tracker (Live AIS)

VesselMMSILast positionAge

Vessels with an MMSI are tracked automatically in the background while the app is running — positions refresh on the map every 20 s.

No AIS key is set, so live positions can't be fetched. A free key takes two minutes - see Settings.

Route & ETA draws the remaining route from the vessel's live position to its destination port and estimates arrival at the default speed.

Add Background Layer

Any route, vessel track, cable, border or corridor to show behind your routes. Files are stored in the layers folder next to the app, so the whole team sees them once SharePoint has synced. Which layers you show is remembered in this browser.

KML, KMZ, GeoJSON, GPX, and tables (CSV / TXT / XLSX with Lat/Lon columns, decimal or deg-min). Route files saved from this app load back as layers. Layers are kept in this browser only. (Shapefile, DXF and GeoPackage need the desktop version.)
KML, KMZ, GeoJSON, GPX, shapefile (zip the .shp, .shx, .dbf and .prj together), GeoPackage, DXF, GML, FlatGeobuf, and tables (CSV / TXT / XLSX with Lat/Lon or Easting/Northing columns). Route files saved from this app (any format) load back as layers.
DXF needs one - DXF files don't say which system they are in (ours are usually UTM). Also needed for tables with Easting/Northing and shapefiles without a .prj. Leave on Auto for everything else.
